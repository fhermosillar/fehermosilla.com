# fehermosilla.com

Personal landing page and printable CV for Felipe Hermosilla Ruiz —
Partner Success & Revenue Operations Lead at Coaches' Voice.

The site works as both an online CV and a print-ready document
(Cmd+P / Ctrl+P from the live site).

## Stack

- [Astro](https://astro.build) — static site framework
- [Tailwind CSS](https://tailwindcss.com) — styling
- [Cloudflare Pages](https://pages.cloudflare.com) — hosting
- Print-optimised via CSS `@media print`

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:4321

## Deploy

Auto-deploys from `main` branch to Cloudflare Pages.
